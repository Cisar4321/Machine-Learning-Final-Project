# Machine-Learning-Final-Project

## Instalación
- Crear entorno: `python -m venv .venv`
- Activar (Windows): `.venv\Scripts\activate`
- Instalar dependencias: `pip install -r requirements.txt`

## Ejecución de la app
- Posicionarse en `app/`: `cd app`
- Ejecutar: `streamlit run app.py`

## Modelo
- Colocar el archivo del modelo CNN en `models/potato_leaf_cnn.h5`.
- Si no está disponible o falta TensorFlow, la app mostrará un aviso.
